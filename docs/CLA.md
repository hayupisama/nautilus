# Accord de contribution (CLA) — Nautilus

> Modèle à faire relire par un juriste avant d'accepter la première contribution externe.

En proposant une contribution (code, documentation, design) à l'un des dépôts du projet Nautilus,
vous acceptez les conditions suivantes :

1. Vous êtes l'auteur de la contribution, ou vous avez le droit de la proposer.
2. Vous accordez au titulaire des droits du projet (Fouad, https://github.com/hayupisama) une licence
   mondiale, non exclusive, gratuite, perpétuelle et irrévocable pour utiliser, reproduire, modifier,
   distribuer et sous-licencier votre contribution, y compris sous d'autres licences, commerciales ou non.
3. Votre contribution est publiée dans le projet sous la licence PolyForm Noncommercial 1.0.0.
4. Vous conservez vos droits d'auteur sur votre contribution.
5. La contribution est fournie « en l'état », sans garantie.

Pour accepter, ajoutez dans la description de votre pull request :
`J'accepte l'accord de contribution de Nautilus (docs/CLA.md).`
