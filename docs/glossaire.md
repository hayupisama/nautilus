# Glossaire FR -> EN

Termes métier et identifiants de code correspondants. À utiliser dans tous les dépôts.

| Français | Code (EN) | Remarque |
| --- | --- | --- |
| Passager | `Passenger` | Personne transportée |
| Réservant | `Booker` | Passager lui-même, aidant ou établissement |
| Aidant | `Caregiver` | Type de réservant |
| Établissement | `Facility` | EHPAD, clinique, centre de rééducation |
| Profil de besoins | `NeedsProfile` | Besoins fonctionnels uniquement, jamais de pathologie |
| Chauffeur | `Driver` | VTC indépendant |
| Véhicule | `Vehicle` | |
| Équipement | `Equipment` | Rampe, hayon, fixations… |
| Justificatif | `DriverDocument` | Carte VTC, registre, assurance, carte grise, attestation PMR |
| Grille tarifaire | `PriceGrid` | Fixée par le chauffeur |
| Prix estimé | `EstimatedPrice` | Calculé par la plateforme, payé directement au chauffeur |
| Disponibilité | `Availability` | Créneaux hebdomadaires |
| Zone d'intervention | `ServiceArea` | Polygone PostGIS |
| Réservation / course | `Booking` | Une seule entité de la demande à la fin de la course |
| Demande non servie | `UnservedRequest` | Statistique anonymisée |
| Recherche de chauffeurs | `DriverSearch` | Filtrage + tri |
| Matching | `Matching` | Contraintes bloquantes puis classement |
| Accompagnant | `Companion` | |
| Personne à prévenir | `EmergencyContact` | Alertée en cas d'incident |
| Signalement | `IncidentReport` | |
| Notation | `Rating` | Note globale + critères PMR |
| Échéance | `Deadline` | Table des tâches planifiées |
| Journal d'audit | `AuditLog` | |
